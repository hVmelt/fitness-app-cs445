# Fitness App

## Team Members

- Mohammad Sarwat
- Ethan Thomas

## Abstract

This project is a fitness web application designed to help users reach their target weight within a user-defined timeframe. Upon signing up, users provide basic profile information — height, weight, age, and gender — which the application uses to generate personalized guidance toward their weight goal. The initial release will focus on core goal-setting and tracking functionality, with additional features introduced iteratively as development progresses under the Agile SDLC methodology.
